# VECTRA Coaching Platform ⚡

Премиальная цифровая экосистема персонального фитнес-наставничества, доказательной биомеханики и спортивной фармакологии **VECTRA**.

Полнофункциональное веб-приложение на **React 19**, **TypeScript**, **Three.js / WebGL** и **Tailwind CSS v4**.

---

## 🌟 Ключевые модули платформы

### 1. 🧬 Интерактивный 3D-Атлас Анатомии (`/atlas`)
* **Реалистичная 3D-модель человека (Écorché)** на Three.js / WebGL.
* **Анатомическая декомпозиция**: 7 базовых групп и 25 детальных мышечных пучков (верх/низ широчайших, 3 пучка грудных, наружное и внутреннее предплечье, бицепс, брахиалис, трицепс, квадрицепсы, бицепс бедра и др.).
* **Динамическая камера и подсветка**: автоматический облёт камеры и неоновый шейдерный фокус выбранной мышцы.
* **Библиотека упражнений**: подборка упражнений с техникой выполнения и целевыми акцентами.

### 2. 🎛️ VECTRA BODY OS (`/body-os`)
* **16-недельный математический симулятор**: расчёт динамики сухой мышечной массы, жировой прослойки и силовых показателей с учётом стажа, дефицита/профицита калорий и фармакологической поддержки.
* **Радар биомаркеров крови**: интерактивная визуализация 8 ключевых биомаркеров (общий и свободный тестостерон, эстрадиол, пролактин, липидный профиль ЛПНП/ЛПВП, гематокрит, печёночные ферменты АЛТ/АСТ, глюкоза) с зонами референсов и риска.

### 3. 📱 Telegram Mini App (`/mini-app`)
* **Мобильный трекер КБЖУ**: визуальное анимированное SVG-кольцо баланса калорий, расчёт съеденного и оставшегося («Осталось / Сверх нормы»).
* **База продуктов и быстрый ввод**: быстрые карточки (красная рыба, говядина, яйца, крупы в сухом весе) с точными макронутриентами.
* **Советы по питанию**: база доказательных рекомендаций по усвоению нутриентов, распределению белка и омега-3.
* **Система напоминаний**: таймеры для тренировок, приёмов пищи и плановой сдачи анализов крови.

### 4. 🧭 Направления и форматы наставничества (`/directions`, `/pricing`, `/apply`)
* Мужские и женские треки (рекомпозиция, сушка, силовой набор, PRO-подготовка).
* Интерактивная форма подачи заявки с валидацией и выбором параметров.

## 🛠️ Стек технологий

* **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion
* **3D Графика**: Three.js, GLTFLoader, MeshoptDecoder
* **Иконки и типографика**: Phosphor Icons (`@phosphor-icons/react`), Manrope, JetBrains Mono
* **Архитектура**: Component-driven architecture, Dark-Navy OLED дизайн-система (`#05080E`, `#0A1120`, `#111C30`, `#3B82F6`)

## 🚀 Быстрый старт

### Требования
* Node.js 18+
* npm 9+

### Установка и запуск

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/Minezii/vectra-coaching.git
   cd vectra-coaching
   ```

2. **Установить зависимости:**
   ```bash
   npm install
   ```

3. **Запустить локальный сервер разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:5173/`.

4. **Сборка для продакшена:**
   ```bash
   npm run build
   ```
